# riski5 — Helsinki Functional Programming meetup presentation

Slide deck for the **2026-05-05 Helsinki Functional Programming meetup**
talk on building [riski5](https://github.com/mikatammi/riski5) — a RISC-V
soft core in [Clash](https://clash-lang.org/) (Haskell), running on a
22-year-old Altera DE2 FPGA, with Linux 6.18.22 booting on real silicon.
